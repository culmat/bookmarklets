A **bookmarklet** is a bookmark whose address is a small JavaScript program instead of a
URL. Clicking it runs that program against the page you are currently looking at — no
extension to install, no permissions to grant, nothing that keeps running in the
background.

## How to install one

1. Make sure your bookmarks bar is visible (<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>B</kbd>,
   or <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>B</kbd> on a Mac).
2. **Drag the blue button** of the bookmarklet you want onto that bar.
3. Open any page and click the new bookmark.

If dragging is awkward, use **Copy** and paste the result into the *URL* field of a
manually created bookmark.

## Source and licence

Every bookmarklet above is generated from the cleartext file linked under its source
listing. The short version you drag is produced at build time — it is never stored as a
second copy, so what you read is exactly what you run.
